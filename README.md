# Greetings — první Git úloha

## Cíl

Na programu `greetings` si vyzkoušíš základní pracovní postup s Gitem:

- práce ve vlastním repozitáři,
- postupné rozšiřování programu,
- smysluplné commity,
- kontrola změn,
- odeslání práce na GitHub.

## Výchozí soubory

V repozitáři jsou tři výukové soubory:

- `01_greetings_README.md`
- `01_greetings_basics_empty.py`
- `01_greetings_basics.py`

Postupuj v tomto pořadí:

1. Přečti `01_greetings_README.md`.
2. Otevři `01_greetings_basics_empty.py`.
3. Vytvoř vlastní pracovní soubor `greetings.py`.
4. Vzorový soubor `01_greetings_basics.py` použij až po vlastním pokusu.
5. Pracuj po malých funkčních krocích.
6. Po každém dokončeném kroku vytvoř commit.
7. Na konci tento README přepiš nebo rozšiř o popis své vlastní verze programu.

## Povinná funkčnost

Program má:

- načíst jméno a příjmení uživatele,
- vypsat osobní pozdrav,
- obsahovat více variant pozdravu,
- náhodně vybrat jednu variantu,
- reagovat na aktuální denní dobu.

## Doporučená Git historie

```text
feat: vytvoří základ osobního pozdravu
feat: přidá náhodný výběr pozdravu
feat: přidá pozdrav podle denní doby
docs: doplní popis a návod ke spuštění
```

## Před odevzdáním

- Program se spustí bez chyby.
- V repozitáři je soubor `greetings.py`.
- Commity mají výstižné zprávy.
- README obsahuje účel programu a návod ke spuštění.
- Všechny změny jsou odeslané na GitHub.
